# Chroma 1.0.0 — Android release candidate

A complete offline single-player colour-code game, with a portrait mobile UI.
Source, generated Android project, web preview assets, tests and store materials
are included. No server, API keys or cloud login are required for the Android app.

## Build your Android App Bundle

1. Install Node.js 22 or newer and Android Studio Otter (2025.2.1) or newer.
   Use Android Studio's bundled JDK **21**. Install SDK Platform 36 and the
   Android SDK build tools offered by Android Studio.
2. Extract this archive. Open a terminal in the folder containing package.json.
3. Run `npm ci` (internet required for dependencies).
4. Run `npm test` to execute rules and UI-flow tests against the included build.
5. Run `npm run android:sync` to rebuild the web assets and sync Android.
6. Run `npm run android:open`, or open the `android` folder in Android Studio.
7. Let Gradle sync. Select a real phone or emulator and press Run. Test the
   checklist in release/RELEASE-CHECKLIST.md, especially small screens, hardware
   Back, background/reopen, native sharing, airplane mode and safe areas.
8. Build > Generate Signed App Bundle / APK > Android App Bundle. Select `app`.
   Create/select YOUR upload key locally; preserve its password and backup.
   Choose release. Do not commit the keystore or credentials.
9. Upload the signed AAB to Play Console's testing track first.

Default application ID: `com.chroma.codebreaker`. Choose and verify your final
unique package ID BEFORE first Play upload; it cannot be changed for that listing.
If you want another ID, change capacitor.config.json appId, Android app namespace
and applicationId, strings.xml package_name/custom_url_scheme, and the Java package
and source directory for MainActivity consistently. Do not create a second
Android project over this one.

Version code is 1 and version name is 1.0.0 in android/app/build.gradle. Increase
versionCode with every Play upload. This source targets SDK 36 and min SDK 24.
Keep Android System WebView current on test devices.

## Features

- Beginner, Classic and Expert difficulty; unlimited random puzzles
- Daily code (same UTC-date code for everyone, one saved attempt per device/day)
- Time attack (three minutes of wall-clock time; no pause exploit on background)
- Introduction, guided example, clue help and replayable practice
- Tap-to-place, editable slots, copy last, clear, desktop drag/drop and keyboard
- Win/loss results, review, retry and optional native result sharing
- Automatic local saves, recovery checks and completed-game records
- Light/dark appearance, colour symbols, optional sound/haptics/reduced motion
- Android Back handling and native splash/adaptive launcher icons
- No ads, accounts, purchases, rankings or tournaments. All visible controls work.

Daily codes are local puzzles, not a secured online competition. Changing a
phone's date or clearing its data can bypass daily progress. A device's data is
not synced to another device; this is an offline product.

## Editing

`src/engine.cjs` owns rules; `src/app.js` owns navigation and state;
`src/style.css` owns the portrait UI. `dist` is generated by `npm run build`.
After editing: `npm run android:sync`, then `npm test`. Do not edit only dist.
`npm run dev` serves the existing dist output locally for browser testing.

## Data / security

Only local game data is stored; no secrets are included. Backup/transfer is
excluded at Android manifest level. Clear progress through Settings. Runtime
internet permission exists but this build has no developer network requests.
Generated WebView assets are bundled, not loaded from the private preview URL.
Adding analytics, ads, billing, or online services changes your privacy and
release obligations and is outside this free v1 release.
